# Verse Clash

A party game where teams write a shared piece from hidden word choices, then reveal it and vote a Crowd Favorite.

## Language

**Room**:
A single game session people join by a short code.
_Avoid_: match, lobby (the place is Lobby)

**Lobby**:
The main room everyone is in except during Selecting.
_Avoid_: Gathering, waiting area, lobby as a Phase

**Breakout**:
The team side-room people enter during Selecting.
_Avoid_: team room, in progress (as the place name)

**Phase**:
The current activity in a Room: Gathering, Prompt, Selecting, Reveal, Voting, Standings, or Ended.
_Avoid_: status, assembling, lobby (as an activity)

**Gathering**:
The Phase in the Lobby before the host starts a round. People join; Teams are not assigned yet unless the host seats someone.
_Avoid_: lobby, waiting

**Prompt**:
The Phase in the Lobby when everyone reads the same authored prompt.
_Avoid_: prompt reveal, prompt_reveal

**Selecting**:
The Phase in the Breakout when each seated player picks one hidden word.
_Avoid_: choosing, team room

**Reveal**:
The Phase in the Lobby when each team’s composition is shown line by line.
_Avoid_: assembling

**Voting**:
The Phase in the Lobby when players pick a Crowd Favorite.

**Standings**:
The Phase in the Lobby when Team win counts are shown after a vote.

**Ended**:
The Phase when the game is over.

**Host**:
The player who starts a round, ends this round, or ends the game, and is never on a Team.
_Avoid_: operator, moderator

**Team**:
A named crew that keeps the same people across rounds and holds a Crowd Favorite win count.
_Avoid_: side, group

**Crowd Favorite**:
The single vote that awards a Team a win for the round.
_Avoid_: score, points
